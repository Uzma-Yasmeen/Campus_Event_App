Features

Built around how campus events actually run

Publish in a minute

Title, time, venue, category and a cover image. Seven categories cover seminars through to sports, so listings stay browsable as they grow.

A QR code on every event

Paste a Google Form link and the code is generated for you. Already had one printed on posters? Upload it and it takes priority.

Know who is coming

Registrations are recorded against the event. Organisers see the full list with names and emails; nobody else can.

Find things fast

Filter by category or search across titles, descriptions and venues. A separate tab keeps the events you registered for to hand.

Web and mobile

A browser client and a React Native app share one API, so an event published on a laptop is on every phone immediately.

Permissions that hold

Roles are enforced on the server, not hidden in the interface. An organiser can only ever edit the events they created.

Getting started

How it works

  1. 1

    Create an account

    Sign up as a participant or an organiser and pick your institution. Not on the list? Add it as you go — nobody gets stuck at sign-up.

  2. 2

    Publish or browse

    Organisers fill in the details and hit publish. Everyone else sees the event straight away, filterable by category and searchable by name.

  3. 3

    Register, or scan

    Register in the app, or scan the event's QR code to open its registration form. Organisers watch the participant list fill up.
